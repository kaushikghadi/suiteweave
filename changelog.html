SuiteWeave – Changelog

Report Builder for NetSuite, by Kaushik Ghadi. What changed in each version. Support · Privacy policy · User guide (PDF)

1.0.19

28 November 2026

Filters

  • Each filter offers only the conditions that fit its field: a checkbox is checked or not, a list field compared by ID is any of or none of, and so on. Conditions in saved reports are kept as they were.
  • Multi-select fields (for example a customer's subsidiaries) match any value you tick; names that contain a comma stay whole.
  • Text with line breaks (addresses) or with Chinese punctuation now matches.
  • Stored codes, such as a transaction status letter, can be used as filter values.
  • Filters by name are sped up only when every name is found; otherwise they stay by name, so no value is dropped.

Fields and columns

  • New reports start with the record's usual columns, like a saved search.
  • More fields now include fields that exist only in saved searches (for example a file's owner), tagged "search". Only those with one value per record are offered.
  • Fields that NetSuite computes slowly are measured in your account and marked "slow".

Value lists

  • The first 200 values appear at once and more keep loading; typing searches all of NetSuite straight away, even while the list is loading.
  • Lists of customers, items, accounts and similar records come straight from that record, sorted by name.

Speed and reliability

  • Reports run straight away, even while SuiteWeave is still checking fields in the background.
  • Lighter Excel files, so large exports open faster. If a large export is interrupted, it stops cleanly and can continue with the next part.
  • Record links open only when SuiteWeave is sure of the record's internal ID.

1.0.17

23 November 2026

  • Name columns and filters are checked before a run: a name NetSuite cannot show, or one that would leave out rows, is shown as its stored value instead.
  • Add all fields of a record in one click (it asks before adding slow ones); move columns to the top or bottom, or drag them into any order.
  • Every field of a record, with a Show: All / Standard / More view; fields NetSuite hides but accepts (for example Script › From Bundle) are offered too.
  • Formula filters on rows, and formulas under Filters on the results.
  • Much faster first pages and exports for wide reports.
  • Transaction status filters by name match only the statuses chosen.
  • Links open files, folders and script deployments; no links for records NetSuite has no page for.
  • Ask AI joins records on NetSuite's own links when your request does not name the fields.

Earlier versions

  • Test releases shared with colleagues before the public launch.
